## English

### Overview

**OpsHome NOC™** helps you monitor the availability of your home network, self-hosted services, personal websites, SSL certificates, and domain-related resources.

It is designed for users who run homelabs, NAS devices, reverse proxies, home servers, personal projects, or small self-hosted services and want to know when something goes offline.

OpsHome NOC™ performs active cloud-based checks and sends real push alerts to your iPhone when a service goes down or recovers.

### Key Features

- **Instant push alerts** when a monitored service goes down or recovers
- **Multiple monitor types** for common homelab and website scenarios
- **Health dashboard** with uptime status and recent activity
- **SSL certificate monitoring** for expiry visibility
- **Event history** for reviewing past incidents
- **Analysis reports** to help understand monitor failures
- **Privacy-focused design** with minimal data collection
- **Sign in with Apple** for simple and secure authentication

### Supported Monitor Types

| Monitor Type | Description | Availability |
| --- | --- | --- |
| HTTP | Website reachability and status code detection | Free / Pro |
| HTTPS | HTTPS reachability with certificate validation | Free / Pro |
| TCP | IP and port connectivity checks | Free / Pro |
| SSL Expiry | SSL certificate remaining validity checks | Free / Pro |
| ICMP Ping | Host reachability checks | Free / Pro |
| UDP | UDP port connectivity detection | Pro |
| DNS | DNS resolution checks | Pro |
| Domain Expiry | Domain expiration tracking | Pro |

## 繁體中文

### 產品介紹

**OpsHome NOC™** 是一款面向個人與家庭場景的網路監控工具，可協助你監控家庭網路、自架服務、個人網站、SSL 憑證與網域相關資源的可用狀態。

它適合正在使用 Homelab、NAS、反向代理、家庭伺服器、個人專案或小型自架服務的使用者，讓你能在服務異常時第一時間知道。

OpsHome NOC™ 會透過雲端主動檢測目標服務，並在服務離線或恢復時，將推播告警即時送達你的 iPhone。

### 核心功能

- **即時推播告警**：服務離線或恢復時即時通知
- **多種監控類型**：支援常見 Homelab 與網站監控場景
- **健康狀態儀表板**：集中查看可用狀態與近期事件
- **SSL 憑證監控**：掌握憑證到期風險
- **事件歷史記錄**：方便回看過去的異常與恢復事件
- **分析報告**：協助理解監控失敗原因
- **隱私優先設計**：僅收集服務運作所需資料
- **使用 Apple 登入**：簡單且安全的身份驗證方式
