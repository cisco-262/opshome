One shared view

A simple page for the services people depend on.

Choose the monitors you want to publish and give others one page to check. Visitors can see the current state, uptime summaries, response times, and recent incident information without opening your monitoring dashboard.

  • Selected services in one public view
  • 24-hour, 7-day, and 30-day uptime summaries
  • Current online state and latest check information
  • Recent incidents and recovery context

What visitors can see

Current status

See whether each selected service is online and review its latest check information.

Uptime summaries

Review 24-hour, 7-day, and 30-day availability at a glance.

Recent incidents

Keep recent service events visible so visitors know whether an issue is active or has recovered.

Links or QR codes

Share one status page link or QR code instead of answering the same availability question repeatedly.

Share by link or QR code. Verify with OpsHome.

QR code sharing

Generate a QR code for a selected status page. Anyone can open it in a browser.

Verify in the OpsHome app

Scan the code in OpsHome to check the official status-page source and load the current report.

Useful for homelabs and small teams

A status page works well for self-hosted services at home, shared tools for a small team, and public projects that need a lightweight availability page. It gives people the information they need while you keep the operational dashboard for yourself.

Use it alongside OpsHome alerts and the iPhone NOC view. When something changes, the status page gives everyone a consistent place to check.

Start with the monitors you already have

Create a status page in OpsHome NOC, select the monitors to display, and share the generated page. You can update the selection or disable the page from the app when your services change.

FAQ

What does a public status page show?
It shows the display names you assign, monitor type, current status, uptime summaries, and the type and time of recent events for the monitors you choose.
Can I choose which monitors appear?
Yes. The page is built around the monitors you select, so you can publish only the services you want others to see.
Can I disable a status page?
Yes. You can disable or delete a status page from OpsHome NOC when it is no longer needed.
Is this the same as the OpsHome monitoring dashboard?
No. A status page is a focused sharing view for selected services. The iPhone NOC view remains the place for your broader monitoring and operations information.
How can I verify a shared report?
Scan the QR code with the OpsHome app. The app checks the official OpsHome status-page source before displaying the current report.
