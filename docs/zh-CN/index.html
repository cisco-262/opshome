// HOW IT WORKS

OpsHome NOC 是如何工作的

OpsHome NOC 不是单机 App，而是由三个部分协同工作的完整 SaaS 服务。

iPhone App

你的控制中心。负责显示实时数据、拓扑图、资产视图和接收告警推送。

OpsHome Cloud

云端 SaaS 服务。负责数据存储、拓扑图生成、告警推送和状态页。

Docker Probe

你部署在内网的轻量探针。采集私有服务状态并安全发送至云端，无需暴露任何端口。

通过 Docker Probe，你的 iPhone 可以实时看到整个 homelab 的状态，完全不暴露任何内网端口。

// FAQ

常见问题

了解安全性、数据传输、方案额度和支持的基础设施。

免费版和 Pro 版的核心区别是什么？
Free 主要用于公网监控，支持最多 30 个公网监控目标。Pro 提高公网监控额度，并增加 Docker Probe 私有网络监控、私有基础设施集成、最多 5 个私有采集节点和 50 个私有监控目标。
能随时取消 Pro 订阅吗？
可以。你可以在 Apple ID 的订阅设置中随时取消。取消后，Pro 权益会持续到当前已付费周期结束。删除 App 或删除 OpsHome 账户不会自动取消 App Store 订阅。
Docker Probe 难安装吗？
按照文档运行提供的 Docker 部署命令即可。熟悉基础 Docker 操作的用户通常可在几分钟内完成安装。 查看部署指南与视频
我的数据安全吗？数据存在哪里？
受支持的监控状态和基础设施指标通过加密 HTTPS传输，并由 OpsHome Cloud 的托管基础设施和数据库服务处理。OpsHome 不要求上传 NAS 文件、文档、照片，也不会接收或保存银行卡信息。
为什么最终价格要在 App Store 确认？
Apple 会根据你的 App Store 地区，在购买前显示本地货币、税费、适用优惠、试用和最终付款信息。OpsHome 不接收或保存银行卡信息。
支持多设备或家庭共享吗？
你可以在另一台受支持设备上使用同一个“通过 Apple 登录”账户，并在需要时恢复有效的 Pro 购买。目前公开的 OpsHome 方案权益不包含家庭共享。
Docker Probe 安全吗？
Docker Probe 主动向 OpsHome Cloud 发起出站连接，不需要配置入站端口转发，也不需要将私有服务直接暴露到公网。
监控数据如何传输？
Docker Probe 采集受支持的服务状态和基础设施指标，再通过加密 HTTPS 连接发送至 OpsHome Cloud API。
关闭 iPhone App 后监控还会继续吗？
会。检测由 OpsHome Cloud 或 Docker Probe 持续执行，iPhone App 用于查看状态、报告和接收通知。
