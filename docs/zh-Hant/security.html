可驗證的安全控制

以下摘要對應目前公開設定與已審計的應用程式控制。

傳輸安全

傳輸中的加密

受保護的連線

後端 API

OpsHome 後端 API 透過 HTTPS 提供存取，Cloudflare 入口最低要求 TLS 1.2。

HSTS 與來源連線

HSTS 已啟用並包含 includeSubDomains。Cloudflare 使用 Full (strict) 模式加密到來源站的連線，並驗證來源站憑證。

憑證保護

敏感憑證與一般監控資料分開處理

服務端敏感憑證

包括 Probe 註冊憑證和驗證密鑰在內的敏感服務端憑證，在寫入資料庫前會使用 AES-256-GCM 加密。

iOS 憑證

iOS App 儲存的驗證令牌使用 Apple Keychain Services 保護。

使用者仍應只授予基礎設施整合所需的權限。

私有監控

Docker Probe，無需入站暴露

Probe 部署在它需要觀察的網路內部。

僅出站通訊

Docker Probe 在授權的私有網路內執行，並主動向 OpsHome Cloud 發起出站 HTTPS 連線。OpsHome Cloud 不會直接連接你的 LAN。

無需公開管理介面

無需開放入站防火牆連接埠、設定連接埠轉發，或透過反向代理公開私有管理面板。

本地存取範圍由你控制

Probe 可以存取你配置的 Proxmox、群暉、Docker、Linux、HTTP、HTTPS 或 TCP 目標。請謹慎選擇目標與權限。

營運資料

Probe 回報健康狀態、狀態變化、事件和有限的資產中繼資料，協助你了解已連接的基礎設施。

存取控制

由使用者控制連接的基礎設施

已驗證帳戶上下文

請求會在已驗證的帳戶上下文中進行校驗。使用者控制哪些基礎設施連接到 OpsHome，以及授予哪些權限。

最小權限

在支援的場景下使用專用監控帳戶或受限權限，避免為監控整合使用不必要的管理員憑證。

公開狀態頁

可選的公開狀態頁只展示選定的狀態資訊，不應暴露私有 IP、主機名稱、URL、容器名稱、內部路徑、API 金鑰或 Probe 識別碼。

共同責任

使用者負責本地主機、Docker 安裝、憑證、權限、網路策略以及選擇的監控目標。

版本完整性

固定 Docker Probe 的準確映像版本

Docker Probe 版本會發布不可變的 OCI 映像摘要。部署時可以固定準確版本，而不只依賴可變標籤。

docker pull opshomenoc/opshome-noc@sha256:<published-digest>
映像摘要用於識別部署時使用的準確映像內容。你可以在 Docker Hub 查看目前公開的版本和摘要。
