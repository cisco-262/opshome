// HOW IT WORKS

OpsHome NOC 是如何運作的

OpsHome NOC 不是單機 App，而是由三個部分協同運作的完整 SaaS 服務。

iPhone App

你的控制中心。負責顯示即時數據、拓撲圖、資產視圖和接收告警推播。

OpsHome Cloud

雲端 SaaS 服務。負責數據存儲、拓撲圖生成、告警推播和狀態頁。

Docker Probe

你部署在內網的輕量探針。採集私有服務狀態並安全傳送至雲端，無需暴露任何連接埠。

透過 Docker Probe，你的 iPhone 可以即時看到整個 homelab 的狀態，完全不暴露任何內網連接埠。

// WHY OPSHOME

別人怎麼做 vs OpsHome NOC 怎麼做

面向希望直接用 iPhone 查看 Homelab 狀態，又不想維護重型監控系統或開放內網入站存取的使用者。

方案 常見痛點 OpsHome NOC 怎麼做
UptimeRobot 主要面向公網端點監控。 在一個 iPhone App 中同時查看公網監控和私有網路狀態。
Uptime Kuma 需要自行部署和維護；遠端查看通常還需要 VPN、反向代理或其他存取路徑。 Docker Probe 主動連線 OpsHome Cloud，無需設定內網入站連接埠轉發。
Prometheus / Grafana 設定複雜、手機端體驗較弱，長期維護成本高。 以 iPhone 為優先，輕量提供儀表板、告警、資產和報告。
VPN + 管理後台 先連接 VPN，再逐一開啟 Synology、Proxmox 或服務後台檢查，操作慢且分散。 開啟一個 App，即可查看目前健康狀態、問題、資產和通知。
暴露 NAS 或服務連接埠 增加內網入站暴露面和安全風險。 私有監控透過 Docker Probe 出站連線完成，無需開放內網入站存取。

// FAQ

常見問題

了解安全性、資料傳輸、方案額度和支援的基礎設施。

免費版和 Pro 版的核心差異是什麼？
普通 Free 主要用於公網監控，支援最多 30 個公網監控目標。Pro 提高公網監控額度，並增加 Docker Probe 私有網路監控、私有基礎設施整合、最多 5 個 Docker Probe 裝置和 50 個私有監控目標。
可以隨時取消 Pro 訂閱嗎？
可以。你可以在 Apple ID 的訂閱設定中隨時取消。取消後，Pro 權益會持續到目前已付費週期結束。刪除 App 或刪除 OpsHome 帳戶不會自動取消 App Store 訂閱。
Docker Probe 難安裝嗎？
按照文件執行提供的 Docker 部署指令即可。熟悉基礎 Docker 操作的使用者通常可在幾分鐘內完成安裝。 查看部署指南與影片
我的資料安全嗎？資料儲存在哪裡？
受支援的監控狀態和基礎設施指標透過加密 HTTPS傳輸，並由 OpsHome Cloud 的託管基礎設施和資料庫服務處理。OpsHome 不要求上傳 NAS 檔案、文件、照片，也不會接收或儲存付款卡資料。
為什麼最終價格要在 App Store 確認？
Apple 會根據你的 App Store 地區，在購買前顯示當地貨幣、稅費、適用優惠、試用和最終付款資訊。OpsHome 不接收或儲存付款卡資料。
支援多裝置或家人共享嗎？
你可以在另一台受支援裝置上使用同一個「透過 Apple 登入」帳戶，並在需要時恢復有效的 Pro 購買。目前公開的 OpsHome 方案權益不包含家人共享。
Docker Probe 安全嗎？
Docker Probe 主動向 OpsHome Cloud 發起出站連線，不需要設定入站連接埠轉發，也不需要將私有服務直接暴露到公網。
監控資料如何傳輸？
Docker Probe 採集受支援的服務狀態和基礎設施指標，再透過加密 HTTPS 連線傳送至 OpsHome Cloud API。
關閉 iPhone App 後監控還會繼續嗎？
會。檢測由 OpsHome Cloud 或 Docker Probe 持續執行，iPhone App 用於查看狀態、報告和接收通知。
