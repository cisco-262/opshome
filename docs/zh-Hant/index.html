FAQ

常見問題

Free 與 Pro 有什麼差異？
普通 Free 提供公網監控，並包含 1 個 Docker Probe、1 個資產源和 1 個私網監控點作為基礎私網體驗。符合條件的 Founder 帳號永久保留 3 組私網額度。Pro 支援 12 個 Docker Probe、12 個資產源、50 個私網監控點、完整基礎設施可見性和進階 Insight。
Docker Probe 安全嗎？
Docker Probe 只主動建立出站連線，不接受入站請求。它僅存取你在 Docker 網路中明確設定的服務，安裝前可以審查公開的部署指令。
Docker Probe 難安裝嗎？
執行提供的 Docker 部署指令並輸入 OpsHome Token。熟悉基礎 Docker 操作的使用者通常幾分鐘即可完成。 查看部署指南。
關閉 iPhone App 後監控還會繼續嗎？
會。檢測由 OpsHome Cloud 或 Docker Probe 持續執行，iPhone App 用於查看狀態、報告和通知。
監控資料如何傳輸？
Docker Probe 透過加密 HTTPS 連線，將受支援的服務狀態和基礎設施指標傳送到 OpsHome Cloud API。
我的資料安全嗎？儲存在哪裡？
監控狀態和受支援的基礎設施指標由 OpsHome Cloud 託管基礎設施及資料庫服務處理。OpsHome 不需要你的 NAS 檔案、文件、相片或付款卡資訊。
可以隨時取消 Pro 訂閱嗎？
可以。在 Apple ID 訂閱設定中管理或取消，Pro 權益會持續到已付費週期結束。
為什麼最終訂閱價格要在 App Store 確認？
Apple 會在購買前顯示當地貨幣、稅費、适用優惠、試用和最終付款確認。OpsHome 不接收或儲存付款卡信息。
可以在多台裝置上使用或進行家庭共享嗎？
你可以在其他受支援裝置上使用同一個「透過 Apple 登入」帳號，並恢復有效的 Pro 購買。目前公開權益不包含家庭共享。
1 分鐘輪詢夠快嗎？服務可能隨時故障。
對大多數 Homelab 情境，一分鐘內發現故障通常足夠。Pro 的 Docker Probe 約每分鐘輪詢私網服務，公網監控最短 5 分鐘。如果關鍵生產服務需要秒級告警，請使用專用的本地告警系統。
如果 OpsHome Cloud 本身無法使用會怎樣？
公網監控將暫停，Docker Probe 心跳也無法到達雲端。我們會監控基礎設施，但不提供正式 SLA。關鍵服務應搭配獨立的備用告警方式。
