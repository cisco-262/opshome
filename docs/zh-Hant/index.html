FAQ

常見問題

Docker Probe 是否需要連接埠轉送？
不需要。Docker Probe 透過出站 HTTPS 連線 OpsHome Cloud，不需要入站連接埠轉送，也不需要公開私有管理介面。
Docker Probe 安全嗎？
Docker Probe 不接受入站請求，只存取你明確設定的私有服務。安裝前可以審查 App 產生的部署指令和公開的安全說明。
關閉 iPhone App 後監控還會繼續嗎？
會。檢測由 OpsHome Cloud 和 Docker Probe 持續執行，iPhone App 用於查看狀態、報告和通知。
Free 和 Pro 有什麼差異？
普通 Free 提供公網監控，並包含 1 個 Docker Probe、1 個基礎設施連線和 1 個私網監控點作為基礎私網體驗。Pro 提升公網和私網監控額度，並提供更完整的基礎設施可見性。
OpsHome 是否替代 Prometheus 和 Grafana？
OpsHome 不替代 Prometheus 或 Grafana。它專注於行動優先的維運可見性，協助管理員快速理解基礎設施健康狀態，而不必維護複雜的監控堆疊。
OpsHome 只適合 Homelab 使用者嗎？
不是。OpsHome 面向 Homelab 愛好者、IT 管理員、網路工程師和小型基礎設施環境。

準備好一眼看清私有基礎設施了嗎？

監控網站、Docker、NAS、Linux、Proxmox、VMware 和 Synology，無需暴露私有管理介面。
