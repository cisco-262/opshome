// 為什麼選擇 OPSHOME

專為 Homelab 可見性而設計

OpsHome NOC 將公網檢測、Docker Probe 私有資產、NAS、Proxmox、Linux 主機、容器、虛擬機和資源健康整合到一个行動優先視圖中。

工具最適合優勢Homelab 取捨OpsHome NOC 定位
UptimeRobot公網在線監控为網站、連接埠、SSL 和域名提供簡單的外部檢測。适合判断公網服務是否離線，但無法看到服务背后的 Homelab 內部狀態。結合公網檢測与私有資產可見性，同時呈現公网端点和 Homelab 內部狀態。
Uptime Kuma自托管在线监控開源、靈活，在 Homelab 使用者中廣泛使用。主要聚焦監控狀態和狀態頁，行動優先的资产可見性並非核心方向。通过行動優先視圖呈现公网检测、Docker Probe 资产、NAS、Proxmox、Linux、容器和虛擬機。
Netdata即時主機遙測提供詳細的 CPU、記憶體、磁碟、網路和程序即時指標。功能強大，但對於只想快速查看 Homelab 概況的使用者可能資訊較密集。側重輕量、聚合的 Homelab 可見性，而非深入的單主機遙測。
Prometheus / Grafana專業可觀測性技術棧強大的指標採集、儀表板、告警和自訂能力。需要設定匯出器、儀表板并持續維護。为不想建置和維護完整監控技術棧的 Homelab 使用者提供更簡單的行動優先可見層。
OpsHome NOC行動優先的 Homelab 可观测性在一個 App 中整合公网监控、Docker Probe 私有可見性、NAS、Proxmox、Linux 主機、容器、虛擬機、CPU、記憶體、存储、SSL 和域名健康。並非用于替代企業級可观测性平台或深度指標系統。補足 Homelab 使用者所缺少的移动可见层。

不同工具適合不同需求。OpsHome NOC 專注於 Homelab 使用者的行動端可見性，把公網監測、Docker Probe 內網資產、NAS、PVE、Linux、容器、虛擬機和資源狀態放在一個清晰視圖裡。

// FAQ

常見問題

了解安全性、資料傳輸、方案額度和支援的基礎設施。

免費版和 Pro 版的核心差異是什麼？
普通 Free 主要用於公網監控，支援最多 30 個公網監控目標。Pro 提高公網監控額度，並增加 Docker Probe 私有網路監控、私有基礎設施整合、最多 5 個 Docker Probe 裝置和 50 個私有監控目標。
可以隨時取消 Pro 訂閱嗎？
可以。你可以在 Apple ID 的訂閱設定中隨時取消。取消後，Pro 權益會持續到目前已付費週期結束。刪除 App 或刪除 OpsHome 帳戶不會自動取消 App Store 訂閱。
Docker Probe 難安裝嗎？
按照文件執行提供的 Docker 部署指令即可。熟悉基礎 Docker 操作的使用者通常可在幾分鐘內完成安裝。 查看部署指南與影片
我的資料安全嗎？資料儲存在哪裡？
受支援的監控狀態和基礎設施指標透過加密 HTTPS傳輸，並由 OpsHome Cloud 的託管基礎設施和資料庫服務處理。OpsHome 不要求上傳 NAS 檔案、文件、照片，也不會接收或儲存付款卡資料。
為什麼最終價格要在 App Store 確認？
Apple 會根據你的 App Store 地區，在購買前顯示當地貨幣、稅費、適用優惠、試用和最終付款資訊。OpsHome 不接收或儲存付款卡資料。
支援多裝置或家人共享嗎？
你可以在另一台受支援裝置上使用同一個「透過 Apple 登入」帳戶，並在需要時恢復有效的 Pro 購買。目前公開的 OpsHome 方案權益不包含家人共享。
Docker Probe 安全嗎？
Docker Probe 主動向 OpsHome Cloud 發起出站連線，不需要設定入站連接埠轉發，也不需要將私有服務直接暴露到公網。
監控資料如何傳輸？
Docker Probe 採集受支援的服務狀態和基礎設施指標，再透過加密 HTTPS 連線傳送至 OpsHome Cloud API。
關閉 iPhone App 後監控還會繼續嗎？
會。檢測由 OpsHome Cloud 或 Docker Probe 持續執行，iPhone App 用於查看狀態、報告和接收通知。
