響應式 Console

一個 Console，多種螢幕尺寸。

OpsHome Console 可從桌面與便攜顯示器自然適配到 iPad 和手機瀏覽器，在不同裝置上保持一致的唯讀運維體驗。

  • 大螢幕與便攜顯示器
  • iPad 橫向
  • iPad 直向
  • 手機瀏覽器

點擊裝置可聚焦查看；在較小螢幕上可左右滑動瀏覽。

01

觀察

將公網服務與 Private Probe 內網目標集中到一個維運視圖。

02

理解

查看基礎設施的健康狀態、利用率、儲存與工作負載。

03

分析

從活躍風險進入受影響資源、證據與事件歷史。

04

展示

使用專注的 Wallboard 取得持續維運可見性。



安全存取

使用 Apple 登入，無需額外密碼。

Console 與 OpsHome NOC 使用同一 Apple 帳戶。身分驗證由 Apple 完成，OpsHome 不會取得或儲存你的 Apple Account 密碼。瀏覽器透過限時工作階段，以唯讀方式存取你現有的 OpsHome 環境。

  • Apple 驗證
  • 傳輸加密
  • 唯讀存取

監控矩陣

公網與內網服務，放在同一個視圖。

將雲端檢查與 Private Probe 目標彙整到統一矩陣中，一眼查看可用性、延遲、協定與目前狀態。

公網 + 內網同時查看網際網路服務與內部服務。
維運矩陣無需逐一開啟詳情頁即可快速掃描目前健康狀態。
即時指標持續展示延遲、可用性與最新觀測結果。

資產拓撲

看到基礎設施，而不只是上線狀態。

在同一個介面理解 Synology、Proxmox、VMware 與 Linux 的運算、儲存、利用率和工作負載。

運算與儲存區分基礎設施角色，同時保留整體視角。
工作負載脈絡將工作負載與 CPU、記憶體、儲存遙測放在一起。
跨平台用一致的介面彙整不同基礎設施平台。

明暗主題

一個 Console，兩種工作方式。

同一套維運視圖可在明亮與暗黑主題之間切換。桌面工作時保持清晰，長時間展示時使用更沉浸的深色介面。

快速開始

從 OpsHome NOC 到 Console，只需三步。

01

使用 OpsHome NOC 監控

在 iOS App 中加入服務檢測與基礎設施資產。

02

在任意瀏覽器開啟 Console

監控點、資產與事件會自動顯示。

03

切換至 Display Mode

使用桌面、平板或更大的螢幕作為維運視圖。

WD

Wall Display 模式

把瀏覽器變成專注的維運牆板，持續展示監控、資產、健康狀態與活躍風險。

  • 即時狀態
  • 全寬佈局
  • 維運矩陣
RO

唯讀設計

查看基礎設施狀態並分析事件，但不把 Web Console 變成遠端管理面板。

  • 不控制基礎設施
  • 維運可見性
  • 證據導向分析

在更大的螢幕上查看你的 OpsHome 環境。

需要更寬的維運視角時使用 Console；離開桌面時繼續用 iPhone 上的 OpsHome NOC。
