Privates Netzwerk · Docker Probe

Sieh in dein privates Homelab
ohne einen einzigen Port zu öffnen

Ein Docker-Befehl auf deinem Server genügt. Der Probe verbindet sich ausschließlich ausgehend mit OpsHome Cloud – dein Heimnetz bleibt für das Internet unsichtbar, für dich aber vollständig sichtbar.

docker run -d opshome/probe:latest \
  -e TOKEN=your_probe_token

Dauert etwa 2 Minuten. Keine Portweiterleitung erforderlich.

FAQ

Häufig gestellte Fragen

Was ist der Unterschied zwischen Free und Pro?
Free umfasst öffentliches Monitoring sowie 1 Docker Probe, 1 Asset Source und 1 privaten Monitor für einfache private Checks. Berechtigte Founder-Konten behalten jeweils 3 private Kontingente. Pro unterstützt 12 Docker Probes, 12 Asset Sources, 50 private Monitore, vollständige Infrastrukturansicht, Telegram und erweiterte Berichte.
Ist Docker Probe sicher?
Docker Probe verbindet sich ausschließlich ausgehend und nimmt keine eingehenden Anfragen an. Er erreicht nur ausdrücklich konfigurierte Dienste im Docker-Netzwerk. Prüfe vor der Installation den veröffentlichten Bereitstellungsbefehl.
Ist Docker Probe schwierig zu installieren?
Führe den bereitgestellten Docker-Befehl aus und gib das Token aus OpsHome ein. Mit Docker-Grundkenntnissen ist die Einrichtung meist in wenigen Minuten erledigt. Bereitstellungsanleitung ansehen.
Läuft das Monitoring bei geschlossener iPhone-App weiter?
Ja. Die Prüfungen laufen über OpsHome Cloud oder Docker Probe weiter. Die iPhone-App dient zum Anzeigen von Status, Berichten und Benachrichtigungen.
Wie werden Monitoring-Daten übertragen?
Docker Probe sendet unterstützte Dienststatus- und Infrastrukturmetriken über eine verschlüsselte HTTPS-Verbindung an die OpsHome Cloud API.
Sind meine Daten sicher und wo werden sie gespeichert?
Monitoring-Status und unterstützte Infrastrukturmetriken werden durch gehostete OpsHome-Cloud-Infrastruktur und Datenbankanbieter verarbeitet. OpsHome benötigt keine NAS-Dateien, Dokumente, Fotos oder Zahlungskartendaten.
Kann ich mein Pro-Abonnement jederzeit kündigen?
Ja. Verwalte oder kündige das Abonnement in den Apple-ID-Abonnementeinstellungen. Pro bleibt bis zum Ende des bezahlten Abrechnungszeitraums verfügbar.
Warum wird der endgültige Preis im App Store bestätigt?
Apple zeigt vor dem Kauf lokale Währung, Steuern, verfügbare Angebote, Testzeiträume und die endgültige Zahlungsbestätigung. OpsHome erhält oder speichert keine Zahlungskartendaten.
Kann ich OpsHome auf mehreren Geräten oder mit Familienfreigabe verwenden?
Du kannst auf einem anderen unterstützten Gerät dasselbe „Mit Apple anmelden“-Konto verwenden und einen aktiven Pro-Kauf wiederherstellen. Familienfreigabe ist derzeit nicht im veröffentlichten Leistungsumfang enthalten.
Reicht ein Prüfintervall von einer Minute?
Für die meisten Homelabs reicht es, einen Ausfall innerhalb einer Minute zu erkennen. Mit Pro prüft Docker Probe private Dienste etwa jede Minute, öffentliches Monitoring frühestens alle 5 Minuten. Für sekundengenaue Alarme produktionskritischer Dienste ist ein spezialisiertes lokales Alarmsystem erforderlich.
Was passiert, wenn OpsHome Cloud selbst ausfällt?
Öffentliches Cloud-Monitoring würde pausieren und Docker-Probe-Heartbeats erreichten die Cloud nicht mehr. Wir überwachen unsere Infrastruktur, veröffentlichen aber kein formales SLA. Nutze für kritische Dienste zusätzlich einen unabhängigen Alarmweg.
