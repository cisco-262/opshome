Private Network · Docker Probe

See inside your private homelab
— without opening a single port

Deploy one Docker command on your server. The Probe makes outbound-only connections to OpsHome Cloud — your home network stays invisible to the internet, but fully visible to you.

docker run -d opshome/probe:latest \
  -e TOKEN=your_probe_token

Takes about 2 minutes. No port forwarding required.

🔒Outbound-only — zero inbound exposure
🐳Monitors Docker containers, NAS panels, internal HTTP/HTTPS/TCP
⏱~1 minute polling interval on Pro

FAQ

Frequently asked questions

What's the difference between Free and Pro?
Free includes up to 30 public monitor targets, one public status page, widgets, and push alerts. Pro raises the limits and adds Docker Probe private monitoring, private infrastructure integrations, Telegram, and advanced reports.
Is Docker Probe secure?
Docker Probe makes outbound connections only and accepts no inbound requests. It reaches only the services you explicitly configure inside its Docker network. Review the published deployment command before installing it.
Is Docker Probe difficult to install?
Run the provided Docker deployment command and enter the token from OpsHome. Users familiar with basic Docker operations can usually finish in a few minutes. View the deployment guide.
Does monitoring continue when the iPhone app is closed?
Yes. Checks continue through OpsHome Cloud or Docker Probe. The iPhone app is used to review status, reports, and notifications.
How is monitoring data transmitted?
Docker Probe sends supported service status and infrastructure metrics to the OpsHome Cloud API through an encrypted HTTPS connection.
Is my data secure, and where is it stored?
Monitoring status and supported infrastructure metrics are processed by hosted OpsHome Cloud infrastructure and database providers. OpsHome does not require your NAS files, documents, photos, or payment card information.
Can I cancel my Pro subscription at any time?
Yes. Manage or cancel the subscription in your Apple ID subscription settings. Pro remains available until the end of the paid billing period.
Why is the final subscription price confirmed in the App Store?
Apple shows the final local currency, taxes, eligible offers, trials, and billing confirmation for your region before purchase. OpsHome does not receive or store your payment card information.
Can I use OpsHome on multiple devices or with Family Sharing?
You can use the same Sign in with Apple account on another supported device and restore an active Pro purchase. Family Sharing is not currently included in the published plan entitlement.
Is 1-minute polling fast enough? My services can go down anytime.
For most homelab use cases, detecting an outage within 1 minute is sufficient. Docker Probe polls private services approximately every minute on Pro. Public monitoring runs at a minimum 5-minute interval on Pro. If you need second-level alerting for production-critical services, use a dedicated on-premise alerting system.
What happens if OpsHome Cloud itself goes down?
Public cloud monitoring would pause, and Docker Probe heartbeats would stop reaching the cloud. We monitor our infrastructure but do not publish a formal SLA. For critical services, pair OpsHome with a secondary alerting method.
