OpsHome NOC 安全

OpsHome NOC 面向透明、注重隐私的基础设施监控而设计。本页面说明服务的安全原则、私有监控部署、访问责任和数据生命周期控制。

安全原则

OpsHome NOC 围绕透明监控、用户可控部署和最小权限实践设计。

  • 通过用户自行部署的组件监控私有基础设施
  • 私有监控环境采用出站连接模型
  • 清晰说明监控与服务运行所需的数据处理
  • 由用户控制已连接的基础设施和授权权限

监控方式

OpsHome 将云端公网服务检测与用户控制的私有监控组件结合使用。

私有监控组件使用出站连接，因此无需通过公网开放内部管理入口。

查看部署与安全说明 ->

数据处理

OpsHome 处理提供监控、历史分析、告警、账户管理和服务功能所需的信息。

  • 账户和订阅信息
  • 监控配置
  • 资产元数据
  • 健康指标与状态信息
  • 运维事件和服务记录

账户安全与访问控制

OpsHome 账户用于安全访问服务、管理订阅、同步配置并提供历史监控功能。

用户控制连接哪些基础设施组件，并负责在自己的环境中配置合适的权限。

最小权限

OpsHome 建议在支持的场景下使用专用监控账户或受限权限。避免为监控集成使用不必要的管理员凭据。

数据生命周期

监控数据保留周期取决于订阅方案、数据类型和服务要求。保留策略用于支持历史视图、分析、排障和可靠的服务运行。

详情请参阅 隐私政策。

用户控制

你控制哪些基础设施连接到 OpsHome NOC、监控组件部署在哪里，以及授予监控集成哪些权限。

Docker Probe 监控不会收集你的私有应用、文件或业务数据内容。
