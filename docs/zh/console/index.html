监控矩阵

公网与内网服务，放在同一个视图。

将云端检查与 Private Probe 目标汇总到统一矩阵中，一眼查看可用性、延迟、协议与当前状态。

公网 + 内网同时查看互联网服务与内部服务。
运维矩阵无需逐个打开详情页即可快速扫描当前健康状态。
实时指标持续展示延迟、可用性与最新观测结果。

资产拓扑

看到基础设施，而不只是在线状态。

在同一个界面理解 Synology、Proxmox、VMware 与 Linux 的计算、存储、利用率和工作负载。

计算与存储区分基础设施角色，同时保留整体视角。
工作负载上下文将工作负载与 CPU、内存、存储遥测放在一起。
跨平台用一致的界面汇总不同基础设施平台。

事件工作区

带着上下文分析事件。

从活跃告警进入受影响资源、现有证据、时间线与事件记录，同时保持 Console 的只读边界。

风险分流在同一列表中优先处理 Critical 与 Warning 事件。
关联资源查看每个事件关联到哪些被监控资源。
回看证据通过时间线与记录理解系统实际观测到了什么。

明暗主题

一个 Console，两种工作方式。

同一套运维视图可在明亮与暗黑主题之间切换。桌面工作时保持清晰，长时间展示时使用更沉浸的深色界面。

响应式 Console

一个 Console，多种屏幕尺寸。

OpsHome Console 可从桌面与便携显示屏自然适配到 iPad 和手机浏览器，在不同设备上保持一致的只读运维体验。

  • 大屏与便携显示器
  • iPad 横屏
  • iPad 竖屏
  • 手机浏览器

点击设备可聚焦查看；在较小屏幕上可左右滑动浏览。
