FAQ

常见问题

Free 与 Pro 有什么区别？
普通 Free 提供公网监控，并包含 1 个 Docker Probe、1 个资产源和 1 个私网监控点作为基础私网体验。符合条件的 Founder 账号永久保留 3 组私网额度。Pro 支持 12 个 Docker Probe、12 个资产源、50 个私网监控点、完整基础设施可见性和高级 Insight。
Docker Probe 安全吗？
Docker Probe 只主动建立出站连接，不接受入站请求。它仅访问你在 Docker 网络中明确配置的服务，安装前可以审查公开的部署命令。
Docker Probe 难安装吗？
运行提供的 Docker 部署命令并输入 OpsHome Token。熟悉基础 Docker 操作的用户通常几分钟即可完成。 查看部署指南。
关闭 iPhone App 后监控还会继续吗？
会。检测由 OpsHome Cloud 或 Docker Probe 持续执行，iPhone App 用于查看状态、报告和通知。
监控数据如何传输？
Docker Probe 通过加密 HTTPS 连接，将受支持的服务状态和基础设施指标发送到 OpsHome Cloud API。
我的数据安全吗？存储在哪里？
监控状态和受支持的基础设施指标由 OpsHome Cloud 托管基础设施及数据库服务处理。OpsHome 不需要你的 NAS 文件、文档、照片或支付卡信息。
可以随时取消 Pro 订阅吗？
可以。在 Apple ID 订阅设置中管理或取消，Pro 权益会持续到已付费周期结束。
为什么最终订阅价格要在 App Store 确认？
Apple 会在购买前显示当地货币、税费、适用优惠、试用和最终付款确认。OpsHome 不接收或存储支付卡信息。
可以在多台设备上使用或进行家人共享吗？
你可以在其他受支持设备上使用同一个“通过 Apple 登录”账号，并恢复有效的 Pro 购买。目前公开权益不包含家人共享。
1 分钟轮询够快吗？服务可能随时故障。
对大多数 Homelab 场景，一分钟内发现故障通常足够。Pro 的 Docker Probe 约每分钟轮询私网服务，公网监控最短 5 分钟。如果关键生产服务需要秒级告警，请使用专用的本地告警系统。
如果 OpsHome Cloud 本身不可用会怎样？
公网监控将暂停，Docker Probe 心跳也无法到达云端。我们会监控基础设施，但不提供正式 SLA。关键服务应搭配独立的备用告警方式。
