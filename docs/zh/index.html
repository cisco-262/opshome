FAQ

常见问题

Docker Probe 是否需要端口转发？
不需要。Docker Probe 通过出站 HTTPS 连接 OpsHome Cloud，不需要入站端口转发，也不需要公开私有管理界面。
Docker Probe 安全吗？
Docker Probe 不接受入站请求，只访问你明确配置的私有服务。安装前可以审查 App 生成的部署命令和公开的安全说明。
关闭 iPhone App 后监控还会继续吗？
会。检测由 OpsHome Cloud 和 Docker Probe 持续执行，iPhone App 用于查看状态、报告和通知。
Free 和 Pro 有什么区别？
普通 Free 提供公网监控，并包含 1 个 Docker Probe、1 个资产源和 1 个私网监控点作为基础私网体验。Pro 提升公网和私网监控额度，并提供更完整的基础设施可见性。
OpsHome 是否替代 Prometheus 和 Grafana？
OpsHome 不替代 Prometheus 或 Grafana。它专注于移动优先的运维可见性，帮助管理员快速理解基础设施健康状态，而不必维护复杂的监控栈。
OpsHome 只适合 Homelab 用户吗？
不是。OpsHome 面向 Homelab 爱好者、IT 管理员、网络工程师和小型基础设施环境。

准备好一眼看清私有基础设施了吗？

监控网站、Docker、NAS、Linux、Proxmox、VMware 和群晖，无需暴露私有管理界面。
