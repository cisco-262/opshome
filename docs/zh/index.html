// HOW IT WORKS

OpsHome NOC 是如何运作的

OpsHome NOC 不是单机 App，而是由三个部分协同运作的完整 SaaS 服务。

iPhone App

你的控制中心。负责显示实时数据、拓扑图、资产视图和接收告警推送。

OpsHome Cloud

云端 SaaS 服务。负责数据存储、拓扑图生成、告警推送和状态页。

Docker Probe

你部署在内网的轻量探针。采集私有服务状态并安全传送至云端，无需暴露任何端口。

通过 Docker Probe，你的 iPhone 可以实时看到整个 homelab 的状态，完全不暴露任何内网端口。

别人怎麽做 vs OpsHome NOC 怎麽做

面向希望直接用 iPhone 查看 Homelab 状态，又不想维护重型监控系统或开放内网入站访问的用户。

方案 常见痛点 OpsHome NOC 怎麽做
UptimeRobot 主要面向公网端点监控。 在一个 iPhone App 中同时查看公网监控和内网状态。
Uptime Kuma 需要自行部署和维护；远端查看通常还需要 VPN、反向代理或其他访问路径。 Docker Probe 主动连接 OpsHome Cloud，无需设置内网入站端口转发。

// FAQ

常见问题

了解安全性、数据传输、方案额度和支持的基础设施。

免费版和 Pro 版的核心差异是什麽？
普通 Free 主要用于公网监控，支持最多 30 个公网监控目标。Pro 提高公网监控额度，并增加 Docker Probe 内网监控、私有基础设施整合、最多 5 个 Docker Probe 设备和 50 个私有监控目标。
可以随时取消 Pro 订阅吗？
可以。你可以在 Apple ID 的订阅设置中随时取消。取消后，Pro 权益会持续到目前已付费周期结束。删除 App 或删除 OpsHome 账户不会自动取消 App Store 订阅。
Docker Probe 难安装吗？
按照文件执行提供的 Docker 部署指令即可。熟悉基础 Docker 操作的用户通常可在几分钟内完成安装。 查看部署指南与视频
我的数据安全吗？数据存储在哪里？
受支持的监控状态和基础设施指标通过加密 HTTPS传输，并由 OpsHome Cloud 的托管基础设施和数据库服务处理。OpsHome 不要求上传 NAS 文件、文件、照片，也不会接收或存储付款卡数据。
为什麽最终价格要在 App Store 确认？
Apple 会根据你的 App Store 地区，在购买前显示当地货币、税费、适用优惠、试用和最终付款信息。OpsHome 不接收或存储付款卡数据。
支持多设备或家人共享吗？
你可以在另一台受支持设备上使用同一个「通过 Apple 登录」账户，并在需要时恢复有效的 Pro 购买。目前公开的 OpsHome 方案权益不包含家人共享。
Docker Probe 安全吗？
Docker Probe 主动向 OpsHome Cloud 发起出站连接，不需要设置入站端口转发，也不需要将私有服务直接暴露到公网。
监控数据如何传输？
Docker Probe 采集受支持的服务状态和基础设施指标，再通过加密 HTTPS 连接传送至 OpsHome Cloud API。
关闭 iPhone App 后监控还会继续吗？
会。检测由 OpsHome Cloud 或 Docker Probe 持续执行，iPhone App 用于查看状态、报告和接收通知。
