// 为什么选择 OPSHOME

专为 Homelab 可见性而设计

OpsHome NOC 将公网检测、Docker Probe 私有资产、NAS、Proxmox、Linux 主机、容器、虚拟机和资源健康整合到一个移动优先视图中。

工具最适合优势Homelab 取舍OpsHome NOC 定位
UptimeRobot公网在线监控为网站、端口、SSL 和域名提供简单的外部检测。适合判断公网服务是否离线，但无法看到服务背后的 Homelab 内部状态。结合公网检测与私有资产可见性，同时呈现公网端点和 Homelab 内部状态。
Uptime Kuma自托管在线监控开源、灵活，在 Homelab 用户中广泛使用。主要聚焦监控状态和状态页，移动优先的资产可见性并非核心方向。通过移动优先视图呈现公网检测、Docker Probe 资产、NAS、Proxmox、Linux、容器和虚拟机。
Netdata实时主机遥测提供详细的 CPU、内存、磁盘、网络和进程实时指标。功能强大，但对于只想快速查看 Homelab 概况的用户可能信息较密集。侧重轻量、聚合的 Homelab 可见性，而非深入的单主机遥测。
Prometheus / Grafana专业可观测性技术栈强大的指标采集、仪表盘、告警和自定义能力。需要配置采集器、仪表盘并持续维护。为不想构建和维护完整监控技术栈的 Homelab 用户提供更简单的移动优先可见层。
OpsHome NOC移动优先的 Homelab 可观测性在一个 App 中整合公网监控、Docker Probe 私有可见性、NAS、Proxmox、Linux 主机、容器、虚拟机、CPU、内存、存储、SSL 和域名健康。并非用于替代企业级可观测性平台或深度指标系统。补足 Homelab 用户所缺少的移动可见层。

不同工具适合不同需求。OpsHome NOC 专注于 Homelab 用户的移动端可见性，把公网监测、Docker Probe 内网资产、NAS、PVE、Linux、容器、虚拟机和资源状态放在一个清晰视图里。

// FAQ

常见问题

了解安全性、数据传输、方案额度和支持的基础设施。

免费版和 Pro 版的核心差异是什麽？
普通 Free 主要用于公网监控，支持最多 30 个公网监控目标。Pro 提高公网监控额度，并增加 Docker Probe 内网监控、私有基础设施整合、最多 5 个 Docker Probe 设备和 50 个私有监控目标。
可以随时取消 Pro 订阅吗？
可以。你可以在 Apple ID 的订阅设置中随时取消。取消后，Pro 权益会持续到目前已付费周期结束。删除 App 或删除 OpsHome 账户不会自动取消 App Store 订阅。
Docker Probe 难安装吗？
按照文件执行提供的 Docker 部署指令即可。熟悉基础 Docker 操作的用户通常可在几分钟内完成安装。 查看部署指南与视频
我的数据安全吗？数据存储在哪里？
受支持的监控状态和基础设施指标通过加密 HTTPS传输，并由 OpsHome Cloud 的托管基础设施和数据库服务处理。OpsHome 不要求上传 NAS 文件、文件、照片，也不会接收或存储付款卡数据。
为什麽最终价格要在 App Store 确认？
Apple 会根据你的 App Store 地区，在购买前显示当地货币、税费、适用优惠、试用和最终付款信息。OpsHome 不接收或存储付款卡数据。
支持多设备或家人共享吗？
你可以在另一台受支持设备上使用同一个「通过 Apple 登录」账户，并在需要时恢复有效的 Pro 购买。目前公开的 OpsHome 方案权益不包含家人共享。
Docker Probe 安全吗？
Docker Probe 主动向 OpsHome Cloud 发起出站连接，不需要设置入站端口转发，也不需要将私有服务直接暴露到公网。
监控数据如何传输？
Docker Probe 采集受支持的服务状态和基础设施指标，再通过加密 HTTPS 连接传送至 OpsHome Cloud API。
关闭 iPhone App 后监控还会继续吗？
会。检测由 OpsHome Cloud 或 Docker Probe 持续执行，iPhone App 用于查看状态、报告和接收通知。
