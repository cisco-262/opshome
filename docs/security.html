OpsHome NOC Security

Last updated: August 24, 2026

OpsHome NOC is designed for transparent, privacy-conscious infrastructure monitoring. This page summarizes the security model, private probe architecture, access responsibilities, and data lifecycle controls used by the service.

Security Principles

OpsHome NOC is designed around transparent infrastructure monitoring, user-controlled deployment, and least-privilege access practices.

  • Private infrastructure monitoring through user-controlled components
  • Outbound communication model for private monitoring environments
  • Transparent data handling for monitoring and service operation
  • User-controlled permissions and connected infrastructure

Monitoring Architecture

OpsHome NOC uses a hybrid architecture that combines private infrastructure monitoring with public service reachability checks.

The complete architecture model, including OpsHome Platform, Probe deployment, Inside-Out Health, and Outside-In Reachability, is documented in our technical documentation.

View Architecture Overview ->

Data Handling

OpsHome processes information required to provide monitoring, historical analysis, alerts, account management, and service functionality.

  • Account and subscription information
  • Monitoring configuration
  • Asset metadata
  • Health metrics and status information
  • Operational events and service records

Account Security and Access Control

Your OpsHome account is used to securely access services, manage subscriptions, synchronize configuration, and provide historical monitoring features.

Users control which infrastructure components are connected and are responsible for configuring appropriate permissions in their own environment.

Least Privilege

OpsHome recommends using dedicated monitoring accounts or limited permissions where supported. Avoid using unnecessary administrative credentials for monitoring integrations.

Data Lifecycle

Monitoring data retention depends on subscription plans, data types, and service requirements. Retention is managed to support historical views, analysis, troubleshooting, and reliable service operation.

For details, see our Privacy Policy.

User Control

You control which infrastructure is connected to OpsHome NOC, where monitoring components are deployed, and which permissions are granted to monitoring integrations.

Docker Probe monitoring does not collect the content of your private applications, files, or business data.
